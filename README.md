# 🚀 Vignesh Ramesh — Developer Portfolio

Welcome to my personal portfolio website! This project is a fully responsive, single‑page application designed to showcase my backend expertise, frontend skills, and passion for clean, interactive design.

---

## 🛠️ Technologies Used
- **HTML5** — Semantic structure and accessibility  
- **CSS3** — Custom styling with dark theme, transitions, and responsive layout  
- **JavaScript (Vanilla)** — Splash → docked intro animation, fade‑in effects, modal interactivity  
- **Font Awesome** — Iconography for skills and contact links  
- **Particle.js** — Animated background for visual depth  

---

## 🎨 Design Highlights
- **Splash intro card** that docks seamlessly into the grid after load  
- **Vertical card grid layout** with smooth fade‑in animations  
- **Dark‑themed UI** with particle background and hover glow effects  
- **Modal system** for detailed content (About, Experience, Skills, Contact)  
- **Skills section** displayed in a horizontal, responsive flex layout for better aesthetics  
- **Interactive contact section** with icons, tooltips, and download links  

---

## 📱 Mobile Optimization
- Adaptive layout with media queries  
- Touch‑friendly buttons and spacing  
- Responsive modals and skill tiles that wrap neatly on smaller screens
